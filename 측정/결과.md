남은 것(이번에 안 함)
- 스캔본에서 편집할 때마다 0.25초: 되돌리기 사본(7번, 나중에).
- 959쪽 저장 0.8초: 글꼴 줄이기(subset_fonts)가 쪽 수만큼 든다. 글꼴을 넣지 않았으면 건너뛸 수 있음.
- 스캔본 → 워드 쪽당 0.68초(8번, 나중에).

바꾼 것
- `sidebar.py`·`organize.py`: `ThumbWorker` 는 부탁받은 쪽만 그린다(나중 부탁부터, 한 장마다 GIL 을 놓음). `LazyThumbs` 가 보이는 칸과 그 아래 한 화면만 부탁하고, 숨은 목록은 안 그린다. 쪽 구조가 바뀌면 옛 쪽 → 새 쪽 대응표(`mapping`)로 안 바뀐 쪽 그림을 옮겨 쓴다(`kept_thumbs`).
- `viewer.py`: 보이는 쪽 앞뒤 3쪽, 합쳐 300MB 까지만 쪽 그림을 남긴다(`_evict`). `rebuild` 도 대응표로 안 바뀐 쪽 그림을 옮겨 쓰고, 그리기 대기 목록을 비운다(안 비우면 그 쪽이 흰 채로 남을 수 있었음). 편집 모드 글자 덩어리는 쪽마다 한 번 읽는다(`blocks`). 닫은 뒤에는 창 맞춤·쪽 이동 타이머가 아무것도 안 한다(`closed`).
- `window.py`: 회전·삭제·순서 바꾸기·뒤집기·복제가 대응표를 넘긴다. 구성 화면은 숨어 있으면 바뀐 쪽 표시만 해 두고 보일 때 그린다. OCR·기울기 보정은 사본(`copy()`)에서 돌리고 끝나면 `adopt()` 로 바꿔 끼운다(되돌리기 사본도 그때 뜸, 그만두면 되돌리기 걸음이 안 남음).
- `document.py`: 그림 데이터를 빼고 글자를 읽는 flags(`TEXT_ONLY`). 검색 결과에 앞뒤 글자를 같이 담는다(`find_text_ctx`). 저장은 평소 `garbage=2`, 다른 PDF 를 끼우거나 쪽을 복제했을 때만 3(`dedupe`). 검색은 쪽마다 잠금을 잡는다.
- 검색 패널: 60쪽 넘는 문서는 일꾼에서 찾는다(20ms 마다 GIL 을 놓아 줌). 목록 칸 높이를 한 번만 잰다.
- `build.py`: 빌드 뒤 `opengl32sw.dll`, Qt Quick·Qml·OpenGL·가상 키보드, Qt TLS 플러그인과 그것만 쓰는 OpenSSL(`-x64` 한 벌), 한국어가 아닌 Qt 번역을 지운다(48MB). 지운 DLL 을 찾는 파일이 없는 것은 `dll_deps.py` 로 확인.

확인한 것
- `pytest app/tests` 65건 통과, `smoke_ui` 통과.
- `check_mapping.py`: 순서 바꾸기·삭제·회전·복제 뒤 옮겨 쓴 썸네일이 모두 제 쪽에 붙고, 회전한 쪽만 새로 그려짐.
- 시험 빌드 exe 를 혼자 띄워 문서·썸네일이 그려지는 것 확인(화면 찍기).
- `bundle_check.py`: 빌드 폴더의 Qt·OpenSSL 만 올려(올린 DLL 6개 모두 빌드 폴더 것) 시험 65건(인쇄·변환 포함)이 통과하고, GitHub 업데이트 확인(HTTPS)도 됨. exe 안에서는 임의 코드를 못 돌려 이 방법으로 대신함.
- 측정 중 `document closed` 오류가 0번(고치기 전에는 문서를 닫을 때마다 남).

## 재다가 본 버그(성능 밖)

- 탭을 닫은 직후 창 맞춤 타이머가 닫힌 문서에서 돌아 `ValueError: document closed` 가 남(화면엔 안 보이고 로그만). `add_doc` 의 60ms 타이머·`_fit_timer` 가 탭이 살아 있는지 안 봄.
- OCR 은 보는 문서(`t.doc.fitz`)를 잠금 없이 일꾼 스레드에 넘김(`window.py` ocr). 그리는 일꾼이 같은 문서를 동시에 만질 수 있어 튕길 위험이 있음(재현은 안 함). 다른 변환은 사본(`d.copy()`)을 넘김.
- 한글(hwpx) 변환은 이 측정 환경(창 없는 파이썬 프로세스)에서 한글 COM `Open` 중 한글이 죽어 못 잼. 앱에서 직접 확인이 필요함.
