# RPDF

알PDF 처럼 쓰는 윈도우용 PDF 편집기. 보기·편집·주석·변환·쪽 구성·OCR·양식·보안까지 한 창에서.

## ⬇️ 다운로드

**[👉 최신 버전 받기 (Releases)](https://github.com/kyijgnes/rpdf/releases/latest)**

- 💻 **Windows** · `PDFEditor-setup-*.exe` 를 받아 실행 (관리자 권한 필요 없음)

> 처음 실행할 때 「Windows의 PC 보호」 창이 뜨면 **추가 정보 > 실행**.

## 쓰는 법

- 설치하면 시작 메뉴·바탕화면에 **RPDF**. PDF 를 끌어다 놓거나 **파일 > 열기**.
- PDF 를 두 번 눌러 바로 열려면 **설정 > 앱 > 기본 앱** 에서 `.pdf` 를 RPDF 로 한 번 고르기.
- 새 버전은 켤 때 저절로 확인. 문서 탭 줄 오른쪽 **[새 버전 x 설치]** 를 누르면 받아서 설치하고 다시 켜짐.
- 지우기: **설정 > 앱 > 설치된 앱 > RPDF > 제거**.
