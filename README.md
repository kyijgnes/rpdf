# PDF 앱 설치 파일

개인용 PDF 편집기의 설치 파일만 올리는 곳입니다(소스는 없습니다).

- **처음 설치**: [최신 릴리스](https://github.com/kyijgnes/pdf-app-releases/releases/latest)에서 `PDFEditor-setup-<버전>.exe` 를 받아 실행합니다. 관리자 권한 없이 내 사용자 폴더(`%LOCALAPPDATA%\Programs`)에 깔립니다.
- **업데이트**: 앱이 켤 때 새 버전을 저절로 확인합니다. 파일 > 업데이트 확인 으로도 볼 수 있습니다. 새 setup 을 덮어 실행해도 설정은 그대로입니다.
- **PDF 를 두 번 눌러 열기**: 윈도우 설정 > 기본 앱 에서 이 앱을 고릅니다.
- **제거**: 윈도우 설정 > 앱 에서 합니다.
